
# Employee Payroll Management System

## Project Description

The Employee Payroll Management System is a Java-based application
that calculates employee salaries and displays payroll details.

## Features

- Employee ID and name input
- Basic salary input
- Allowance input
- Deduction input
- Gross salary calculation
- Net salary calculation
- Payroll report display

## Technologies Used

- Java
- Visual Studio Code
- Git
- GitHub

## Workflow

1. Enter employee details.
2. Enter basic salary.
3. Enter allowance.
4. Enter deduction.
5. Calculate gross salary.
6. Calculate net salary.
7. Display payroll report.

## How to Run

1. Install Java JDK.
2. Open the project in VS Code.
3. Open the terminal.
4. Compile the code:

   javac -d out src\Main.java

5. Run the program:

   java -cp out Main
